# Data licensing and attribution

The Apache-2.0 license in this repository applies to source code and documentation
created for this project. It does not relicense Wikipedia text or generated datasets.

Wikipedia text is generally available under Creative Commons Attribution-ShareAlike
terms, with additional terms and possible exceptions. Before redistributing generated
Parquet or token shards:

- review the [Wikimedia Terms of Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use/en#7._Licensing_of_Content);
- retain the source dump name, date, URL, and checksum;
- retain page and revision identifiers, titles, canonical URLs, and modification notice;
- provide the applicable license notice and attribution path;
- determine whether your distribution and transformations trigger additional obligations.

The manifest and document schema preserve inputs needed for an attribution strategy,
but they are not a legal determination. Obtain qualified legal review before releasing
a derived corpus when compliance matters. This repository ships code and synthetic
test fixtures, not a Wikipedia corpus.
